# 公文格式自动排版助手

依据《关于进一步规范公文格式的通知.docx》（GB/T 9704-2012 党政机关公文格式）的格式规范，
对写好的 `.docx` 公文做**半自动**格式调整：自动识别各段落角色（标题/主送机关/正文/各级标题/
附件说明/发文机关署名/成文日期/附注/版记），逐段列出供人工确认或修改，确认后一键套用格式，
另存新文件并自动用 WPS 打开结果。

## 功能

- 页面设置：A4，上 37 / 下 34 / 左 28 / 右 26 mm，页眉 15 / 页脚 30 mm，每面 22 行 × 28 字网格；
  横向节仅套用公文页边距，保留纸张方向
- 各要素字体/字号/固定行距/对齐/字符缩进（标题 2 号方正小标宋居中 35 磅；正文 3 号仿宋_GB2312
  两端对齐 29 磅首行缩进 2 字；一级标题黑体、二级楷体_GB2312；发文机关署名右空 6 字、成文日期右空 5 字）
- 段前段后、左右缩进统一置 0；标题与主送机关之间空 1 行、附件说明前空 1 行、发文机关署名前空 2 行
  （自动补足或删除多余空行）
- 页码：样式“— N —”，位置“双面打印1”（外侧：奇数页右、偶数页左），4 号宋体，
  两端对齐，缩进文本前/后各 1 字符，单倍行距（值 1），应用整篇文档
- 半自动：逐段清单 + 角色下拉可改（含「删除」选项），确认后套用
- 批量：多文件批量添加、一键全部套用
- 规则管理：显示当前规则，可新增/删除角色、编辑字体字号行距对齐
- 字体检查：启动时检测规则所需字体是否安装
- 版头/版记模板套用：内置模板 + 下拉框自主选择；可填写发文字号、签发人姓名、日期
  （日期同时替换成文日期与印发日期）；原文件中的版头、页码、版记自动删除
- 输出：`<原名>_已排版.docx`，完成后自动用 WPS 打开

## 运行

### 方式一：直接运行 exe（推荐）

双击 `dist\公文格式自动排版助手.exe` 即可。

- 规则：程序内置默认规则；如需覆盖，可在 exe 同目录放一个 `rules.json`（点「规则设置…」里的
  「用文本编辑器打开 rules.json」可生成并编辑）。
- 版头模板：已内置打包进 exe；如需增补或覆盖，可在 exe 同目录建 `template` 文件夹放入 `.docx`，
  同名以该目录为准。

### 方式二：源码运行（开发）

```powershell
python -m pip install python-docx PySide6
python launcher.py
```

## 规则配置（rules.json）

格式标准全部集中在 `app/rules.json`，主要分块：

- `page`：纸张、页边距、页眉页脚、行列数
- `fonts` / `sizes_pt` / `line_spacing_pt` / `alignment`：按角色（title/body/h1/h2/…）配置字体、字号、行距、对齐
- `indent`：各角色的字符级缩进
- `page_number`：页码格式
- `output`：输出文件后缀

界面里的「规则设置…」可快速改常用项；「用文本编辑器打开 rules.json」可改全部项。

## 字体说明

规范所需字体：方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体、宋体、Times New Roman。
若某字体未安装，程序启动会在状态栏提示；可在规则里改成近似字体（如标题→黑体、正文→仿宋、
二级→楷体）。

## 版头模板

模板已内置打包进 exe；如需增补/覆盖，在 exe 同目录建 `template` 文件夹放入 `.docx`。
启动后左侧「版头模板」下拉框自动列出，选择后套用；选「（不添加版头）」则不套用。

选择模板后，下方「发文字号」「签发人」输入框会自动带入模板里的占位内容（如 `白委〔2026〕×号`、
`王丽容`），可直接改成实际值。填写规则：

- 发文字号、签发人**都未填**：发文字号行**只保留红线**（清除发文字号、签发人等全部文本）；
- **只填发文字号**（签发人留空）：发文字号**居中**排列，并**删除签发人**；
- **都填**：发文字号**左空一字**靠左，签发人**右空一字**靠右；除签发人姓名外中文字体为
  仿宋_GB2312、西文 Times New Roman，签发人姓名为楷体_GB2312。

套用方式：以模板为底，保留其红头、发文字号、红线（VML 矢量图形），把用户文档的标题与正文
追加到红线下方（空二行），再统一页面与页码。

## 目录结构

```
app/
  main.py            # PySide6 主界面
  classifier.py      # 结构识别分类器
  converter.py       # 文档格式转换器
  formatter.py       # 格式应用引擎（页面/段落/页码）
  rules_config.py    # 规则加载/保存
  rules.json         # 规则配置（可编辑）
  docx_io.py         # docx 底层与 OOXML 辅助
  notice_import.py   # 从《通知》导入/校验规则
  template_apply.py  # 版头模板套用
  font_check.py      # 字体检测
  wps_launch.py      # WPS 定位与启动
template/            # 版头模板文件夹（打包时内置，exe 旁可覆盖增补）
test_smoke.py        # 端到端冒烟测试
test_notice.py       # 通知导入/校验测试
test_template.py     # 版头模板套用测试
test_issuer.py       # 发文字号/签发人填写测试
test_page_number.py  # 页码格式测试
```

## 打包 exe

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name "公文格式自动排版助手" `
  --add-data "app/rules.json;app" --add-data "template;template" launcher.py
```

## 当前范围与已知限制

- 覆盖：页面设置 + 主体 + 版记（页码）+ 版头模板套用（内置模板，可填发文字号/签发人）
- 结构识别为启发式 + 人工确认；主送机关无冒号、附注等边缘情况请以人工确认为准
- 保留原样：横向节（纸张方向，但套用公文页边距）、图片、表格、分页符等；页码西文/中文统一宋体
- 套用模板时以源文档为底、把版头插入开头，版头与标题之间固定空二行
- 空行由程序统一管理：标题→主送 1 空、附件说明前 1 空、署名前 2 空（其余位置保留原文空行）
